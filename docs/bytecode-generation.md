# 字节码生成说明

**状态：`PROPOSED`（提议）——所有与具体格式相关的行为均为 `UNVERIFIED`（未验证）。**

## 预期的流水线

1. 校验 FunctionDescription。
2. 解析符号标识与签名。
3. 校验变量与参数。
4. 构建控制流标签。
5. 构造受支持的 UAssetAPI 表达式对象。
6. 在需要处计算序列化布局。
7. 校验表达式结构与引用。
8. 在隔离的资产副本中替换目标函数。
9. 序列化到新文件。
10. 重新读取并校验输出。

## 符号引用

函数引用不应只携带一个短名称。优先携带包/模块路径、所属类、函数名、签名或签名指纹，以及任何必需的目标对象上下文。

有歧义的匹配必须产出诊断信息，而不是悄悄选一个。

## Import 构造

- 首先搜索当前包的 Exports 与 Imports。
- 按完整对象标识与 Outer 链去重。
- 根据实际的目标版本与样本证据，构造所需的 outer/package/class/function 关系。
- 绝不从全局元数据或另一个资产复制包内局部的 FPackageIndex 值。

## 控制流

跳转偏移的表示与序列化规则对版本敏感。绝不要假定表达式列表索引就是字节偏移。要对照实际的 UAssetAPI 实现与真实的序列化样本验证该行为。在这一点被证明之前，禁用不受支持的控制流生成。

## 验证

序列化器调用成功并不足够。要重新读取输出，检查目标函数标识、受支持的表达式结构、引用合法性，以及意外的结构改动。运行时正确性需要单独的目标引擎或目标工程验证步骤。

## 最小编辑路径（ADR 0002）

与上文生成流水线**并列**的第二条路径，面向既有函数。详见 [ADR 0002](decisions/0002-dual-path-bytecode.md)。

1. 只读解析目标函数的表达式数组。
2. 定位目标表达式与目标字段（参数槽位 / 常量字面量）。
3. 在**不改变表达式数量、不改变该表达式序列化长度**的前提下替换值。
4. 写回并读回校验。

硬性限制：

- **不允许插入 / 删除 / 移动表达式**——那会改变跳转偏移，属于生成路径的范畴，且必须先解决偏移重算。
- **若新值的序列化长度与原值不同**（字符串、`FName`、数组、结构体），必须**拒绝并报错**，不得静默写出。长度变化会让其后所有跳转偏移失效。
- 长度不变时偏移天然有效，但这只是推理，**仍要在读回时实际验证跳转目标没有错位**。

这条路径的存在不改变 §5「UKAPI 是单向的」：生成仍然是单向的，编辑不伪装成生成。
