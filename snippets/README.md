# 代码片段

本目录包含用于讨论领域设计的小型、相互隔离的示例。片段不一定达到生产可用程度，也绝不能被误认为一个可用的字节码编译器。

每个片段都应记录：
- 目的。
- 假设与受支持的范围。
- 依赖。
- 验证状态。
- 它明确不实现的内容。
